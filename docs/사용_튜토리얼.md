## 1. 시작하기

### 1.1 로그인·회원가입

- 앱에 접속하면 **로그인 화면**이 나타납니다.
- **이메일**과 **비밀번호(6자 이상)**를 입력한 뒤:
  - **로그인**: 기존 계정으로 들어갑니다.
  - **회원가입**: "회원가입" 링크를 눌러 이름·이메일·비밀번호를 입력하면 새 계정이 만들어집니다.
- 가입 직후에는 **로컬에서만** 프로젝트와 작업을 만들 수 있습니다. 관리자 승인 후에 서버와 **동기화**가 가능해집니다.

### 1.2 첫 화면 구성

- 로그인 후 **상단 네비게이션**에서 화면을 바꿀 수 있습니다.
  - **대시보드**: 프로젝트·상태·인원별 현황 요약
  - **투입현황**: 프로젝트별·인원별 투입 비율·공수(M/D)
  - **표+간트**: WBS 표와 간트 차트를 나란히 보며 편집
  - **표만** / **간트만** / **칸반** / **마인드맵**: 각각 작업 목록·일정·상태·계층 구조 보기
  - **프로젝트**: 프로젝트 목록과 생성·수정·삭제·공유
- **프로젝트 선택**: 상단의 프로젝트 이름을 클릭하면 현재 보고 있는 프로젝트를 바꿀 수 있습니다.

## 2. 프로젝트 만들기와 관리

### 2.1 프로젝트 생성

1. 상단 메뉴에서 **프로젝트** 탭을 클릭합니다.
2. **프로젝트 추가** 버튼을 누릅니다.
3. **이름**, **설명**, **시작일·종료일**(선택) 등을 입력하고 저장합니다.
4. 생성된 프로젝트를 클릭하면 해당 프로젝트의 작업을 편집할 수 있습니다.

### 2.2 프로젝트 수정·삭제·복사

- **프로젝트** 화면에서 카드의 **연필 아이콘**으로 수정, **휴지통**으로 삭제할 수 있습니다.
- **복사**를 누르면 같은 이름·작업이 포함된 새 프로젝트가 만들어지며, 복사본은 **내 소유**로 등록됩니다.

### 2.3 프로젝트 기간과 투입

- 프로젝트 편집에서 **시작일·종료일**을 넣으면, 해당 기간 밖의 작업 일정은 제한됩니다.
- **투입 인원·비율**을 설정하면 **투입현황** 화면에서 프로젝트별·인원별 투입을 한눈에 볼 수 있습니다.

## 3. 작업(WBS) 추가·편집하기

### 3.1 작업 추가

- **표+간트** 또는 **표만** 뷰에서:
  - **Enter**: 선택한 작업과 같은 레벨 아래에 새 작업 추가
  - **Tab**: 선택한 작업을 한 단계 하위 레벨로 내리기
  - **Shift+Tab**: 한 단계 상위 레벨로 올리기
- 표에서 **작업 행을 더블클릭**하거나 **F2**를 누르면 **작업 편집 창**이 열립니다. 여기서 이름·일정·담당자·상태·공수·산출물·선행작업 등을 입력합니다.

### 3.2 작업 순서·구조 변경

- **Alt+↑/↓**: 선택한 작업의 순서를 위·아래로 이동
- **드래그 앤 드롭**: 작업을 끌어다 놓아 순서나 부모를 바꿀 수 있습니다(표·칸반 등에서 지원).
- **Delete**: 선택한 작업 삭제(하위 작업 포함 여부는 확인 창에서 선택)

### 3.3 복사·붙여넣기

- **Ctrl+C**: 선택한 작업(및 하위) 복사
- **Ctrl+V**: 복사한 작업을 선택 위치 아래에 붙여넣기
- **Ctrl+A**: 전체 선택 후 한 번에 복사할 수도 있습니다.

### 3.4 일정·공수·담당자

- **작업 편집 창**에서 **시작일·종료일**, **공수(일)**, **담당자**, **상태**, **진척률** 등을 입력합니다.
- **선행작업(의존성)**을 지정하면 간트에서 선으로 연결되고, 일정이 자동으로 반영될 수 있습니다.
- **간트만** 뷰에서는 막대를 **드래그**해 일정을 바꿀 수 있습니다.

## 4. 다양한 화면(뷰) 사용하기

| 뷰 | 용도 |
|----|------|
| **표+간트** | 표에서 작업을 편집하고, 오른쪽 간트에서 일정·선후관계를 동시에 확인. 가운데 구분선을 드래그해 비율 조절 가능. |
| **표만** | 작업 목록만 크게 보기. 정렬·필터·복사·붙여넣기에 적합. |
| **간트만** | 일정 막대만 보기. 확대/축소(+/-), 막대 드래그로 일정 변경. |
| **칸반** | 상태별 칸(예: 대기·진행·완료)으로 작업을 옮겨 진행 상황을 시각적으로 관리. |
| **마인드맵** | WBS를 트리 형태로 표시. 노드 클릭으로 작업 편집. (관리자 등 권한에 따라 비활성화될 수 있음) |
| **대시보드** | 프로젝트 수, 작업 수, 상태별 개수, 인원별 현황 등을 카드로 요약. |
| **투입현황** | 프로젝트별·인원별 투입 비율과 공수(M/D)를 표로 확인. |
| **프로젝트** | 프로젝트 목록, 추가·수정·삭제·복사·공유. |

## 5. 가져오기·내보내기·백업

### 5.1 가져오기

- 상단 **⋮(더보기)** → **가져오기**를 선택합니다.
- **Excel(.xlsx)** 또는 **백업 JSON(.json)** 파일을 선택할 수 있습니다.
- Excel: 시트 구조에 맞춰 미리보기 후 **기존 프로젝트에 합치기** 또는 **새 프로젝트로 만들기**를 선택해 가져옵니다.
- JSON: 이 앱에서 내보낸 백업 파일을 그대로 복원하거나, 여러 파일을 선택해 **다중 병합**할 수 있습니다.

### 5.2 내보내기

- **⋮** → **내보내기**를 누르면 **내보내기** 창이 열립니다.
- **범위**: 전체 프로젝트 / 선택한 프로젝트만
- **형식**: Excel / JSON(백업) / Markdown
- 설정 후 **내보내기**를 누르면 파일이 다운로드됩니다.
- 한 번 설정해 두면 다음에는 **마지막 설정으로 빠른 내보내기**도 가능합니다.

### 5.3 백업 권장

- 데이터는 브라우저 로컬에 저장됩니다. **정기적으로 내보내기(JSON)**로 백업해 두는 것을 권장합니다.
- 상단에 "정기적으로 내보내기로 백업을 하시기 바랍니다" 배너가 나올 수 있으며, **내보내기** 버튼으로 바로 백업할 수 있습니다.

## 6. 프로젝트 공유와 협업

### 6.1 공유(초대)하기

- **프로젝트** 화면에서 공유할 프로젝트 카드의 **공유(Share)** 버튼을 누르거나, 표/간트 화면에서 **⋮** → **공유**를 선택합니다.
- **초대 링크 만들기**를 누르면 링크가 생성됩니다. 이 링크를 팀원에게 보내면 **보기** 또는 **편집** 권한 요청을 할 수 있습니다.
- **멤버 추가**: 회원 목록에서 사용자를 선택해 **편집** 또는 **보기** 권한을 부여할 수 있습니다(소유자 또는 관리자만 가능).

### 6.2 권한 요청·승인

- 초대 링크로 들어온 사용자는 **보기/편집 권한 요청**을 보낼 수 있습니다.
- 프로젝트 소유자(또는 관리자)는 **멤버** 관리 화면에서 요청을 **승인** 또는 **거절**할 수 있습니다.
- 승인되면 해당 프로젝트가 목록에 보이고, 권한에 따라 보기만 하거나 편집할 수 있습니다.

---

## 7. DB 동기화

- 관리자 **승인을 받은 사용자**만 **DB 동기화**를 사용할 수 있습니다.
- **Ctrl+S** 또는 상단 **동기화** 관련 버튼을 누르면 **로컬 데이터**와 **서버(Supabase)** 데이터를 맞춥니다.
- 동기화 시 **업로드(로컬→서버)**와 **다운로드(서버→로컬)**가 함께 이루어지며, 충돌 시 안내에 따라 선택할 수 있습니다.
- 미승인 사용자는 "승인 후 서버와 동기화할 수 있다"는 안내만 보입니다.

## 8. 유용한 단축키

### 공통

| 단축키 | 동작 |
|--------|------|
| **Ctrl+Z** | 되돌리기 |
| **Ctrl+Alt+1~9** | 트리를 1~9 레벨까지 펼치기 |
| **Ctrl++** / **Ctrl+-** | 표·간트 줄 높이 늘리기/줄이기 |
| **Ctrl+S** | DB 동기화(로컬↔서버) |

### 표(WBS)

| 단축키 | 동작 |
|--------|------|
| **↑ / ↓** | 선택한 행 이동 |
| **Alt+↑ / Alt+↓** | 작업 순서 위/아래로 변경 |
| **Tab** | 레벨 한 단계 내리기 |
| **Shift+Tab** | 레벨 한 단계 올리기 |
| **Enter** | 같은 레벨 아래에 새 작업 추가 |
| **F2** | 선택한 작업 수정 |
| **Delete** | 선택한 작업 삭제 |
| **Ctrl+C** / **Ctrl+V** | 복사 / 붙여넣기 |
| **Ctrl+A** | 전체 선택 |
| **Esc** | 선택 해제 |

### 간트

| 단축키 | 동작 |
|--------|------|
| **+ / =** | 확대 |
| **-** | 축소 |

### 마인드맵

| 동작 | 방법 |
|------|------|
| 캔버스 이동 | 배경 드래그 |
| 확대·축소 | **Ctrl+휠** |

- **키보드 아이콘**을 누르면 단축키 패널을 열어 목록을 볼 수 있습니다.

## 9. AI 분석·주간보고·기타

### 9.1 AI 분석

- **⋮** → **AI 분석**을 선택하면 **Gemini**를 이용한 보조 기능을 쓸 수 있습니다.
- WBS 초안 생성, 재분석, 의존성 추론 등을 지원합니다. (API 키 설정이 필요할 수 있습니다.)

### 9.2 주간보고

- **⋮** → **주간보고**를 누르면 **기준 주**를 선택하고, 담당별·프로젝트별로 요약된 주간 보고 내용을 볼 수 있습니다.
- 요약 텍스트를 복사해 쓰거나, 링크를 통해 해당 작업으로 바로 이동해 수정할 수 있습니다.

### 9.3 버전(히스토리)·설정

- **버전 관리**: 앱 내에서 버전 히스토리를 확인할 수 있는 기능이 있을 수 있습니다. 개발/배포 버전 원복은 `docs/버전_히스토리_원복용.md`를 참고하세요.
- **WBS 설정**: **⚙ 설정**에서 **상태 정의**, **WBS 레벨·접두어**, **표 컬럼 표시** 등을 바꿀 수 있습니다.
- **전체 초기화**: **⋮** → **데이터 초기화** 등으로 로컬 데이터를 비울 수 있습니다. 반드시 필요한 경우에만 사용하고, 미리 **내보내기(JSON)**로 백업해 두세요.

---

## 요약

1. **로그인/가입** → **프로젝트**에서 프로젝트를 만들고 선택합니다.
2. **표+간트** 또는 **표만**에서 **Enter**, **Tab**, **F2**로 작업을 추가·편집합니다.
3. **간트·칸반·대시보드·투입현황**으로 일정·상태·현황을 확인합니다.
4. **가져오기/내보내기**로 Excel·JSON 백업을 활용합니다.
5. **공유**로 팀원을 초대하고, **DB 동기화**로 서버와 데이터를 맞춥니다.
6. **Ctrl+S**(동기화), **Ctrl+Z**(되돌리기) 등 **단축키**를 쓰면 작업이 더 빨라집니다.

추가 기능은 **기능정의서.md**를 참고하시면 됩니다.
