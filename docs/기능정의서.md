# 기능 정의서 (Functional Specification)

> **지엠티 프로젝트 매니저**의 기능을 사용자·기획·검수 관점에서 정의한 문서입니다.  
> 상위 요구사항: [user_requirement.md](../user_requirement.md)(URS), [system_requirement.md](../system_requirement.md)(SRS).

---

## 1. 문서 개요

| 항목 | 내용 |
|------|------|
| **대상 제품** | 지엠티 프로젝트 매니저 (WBS_MG) |
| **목적** | 기능 단위 정의로 기획·개발·검수·운영 시 공통 기준 제공 |
| **관련 문서** | URS(사용자 요구사항), SRS(시스템 요구사항), CHANGELOG, 마이그레이션 |

---

## 2. 제품 개요

| 항목 | 내용 |
|------|------|
| **제품명** | 지엠티 프로젝트 매니저 (앱 설정에서 표시 제목 변경 가능) |
| **목적** | 여러 프로젝트의 WBS(작업 분해)를 한곳에서 관리하고, 일정·담당·진행을 여러 뷰로 보고, 팀과 공유하며, 서버 동기화·AI·주간보고로 업무를 보조 |
| **주요 사용자** | 프로젝트/과제 담당자, 팀 리더, (선택) 시스템 관리자 |
| **UI 언어** | 한국어 |
| **접근** | 웹 브라우저(반응형) |

## 3. 기능 목록 요약

| 영역 | 주요 기능 |
|------|-----------|
| **인증·회원** | 이메일/비밀번호·OAuth 가입/로그인, 승인 전/후 구분, 관리자 앱 비밀번호 |
| **프로젝트** | 생성·수정·삭제·복사, 기간·투입·주간보고 메타, 기간 내 작업 일정 제한 |
| **작업(WBS)** | 트리 구조, WBS 번호, 속성(일정·진행·담당·상태·공수·선행·베이스라인 등), 추가/삭제/순서/들여쓰기, 일괄 수정 |
| **화면(뷰)** | 표+간트, 표만, 간트만, 칸반, 마인드맵, 대시보드, 프로젝트, 투입현황 |
| **필터·정렬** | 프로젝트 다중 선택, 상태·담당자·기간·마일스톤/이슈/레벨/기한 지난/이번 주 완료 등, WBS·컬럼 정렬 |
| **설정** | 앱 제목, WBS 레벨·접두어, 상태 정의·진척도, 표 컬럼·줄바꿈·열 너비, 간트 크리티컬 패스 |
| **협업** | 소유/편집/보기 역할, 초대 링크, 보기·편집 권한 요청·승인/거절 |
| **데이터** | DB 동기화, Excel/JSON 가져오기·보내기, Markdown 요약, 전체 초기화 |
| **AI 보조** | WBS 초안 생성·재분석·의존성 추론, API 키·첨부·미리보기·잠금 필드 |
| **주간보고** | 기준 주 선택, 담당/전체·프로젝트 범위, 요약 텍스트 복사·작업 바로 수정 |
| **감사·이력** | 프로젝트별 생성·수정·삭제 기록 시간순 조회 |
| **관리자** | 회원 목록·승인·계정 삭제, 앱 비밀번호로 보호 |

## 4. 인증·회원

### FD-AUTH-01 회원가입·로그인
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-AUTH-01 |
| **기능명** | 회원가입·로그인 |
| **설명** | 이메일과 비밀번호로 가입·로그인한다. Google·GitHub 계정으로도 로그인할 수 있다. 비밀번호는 일정 길이 이상이어야 한다. |
| **입력** | 이메일, 비밀번호 / OAuth 제공자 선택 |
| **결과** | 로그인 성공 시 앱 메인으로 이동, 세션 유지 |
| **화면** | 로그인/가입 폼(헤더 또는 전용 뷰) |

### FD-AUTH-02 가입 직후 경험
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-AUTH-02 |
| **기능명** | 가입 직후 즉시 사용 |
| **설명** | 가입 직후에도 앱을 바로 쓸 수 있다. 로컬에서 프로젝트·작업 생성·편집이 가능하다. 관리자 승인 전에는 서버와의 동기화(업로드/다운로드)는 할 수 없다는 안내가 표시된다. |
| **조건** | 미승인(profiles.approved = false) |
| **결과** | 로컬 저장만 가능, 동기화 버튼 비활성 또는 안내 배너 |

### FD-AUTH-03 승인 후 동기화
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-AUTH-03 |
| **기능명** | 승인 후 서버 동기화 |
| **설명** | 관리자 승인을 받은 사용자는 서버와 데이터를 맞출 수 있다(협업·다른 기기 반영). 승인된 사용자는 등록된 모든 프로젝트 목록을 볼 수 있고, 타인 프로젝트의 작업 내용도 읽을 수 있다. 편집은 초대·멤버로 권한이 있을 때만 가능하다. |
| **조건** | profiles.approved = true |
| **결과** | 동기화 실행 가능, 프로젝트 목록·작업 읽기 권한 확장 |

### FD-AUTH-04 관리자 보호
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-AUTH-04 |
| **기능명** | 관리자 모드 보호 |
| **설명** | 관리자 모드(회원 목록·승인·계정 삭제 등)는 앱 비밀번호 등으로 보호될 수 있다. |
| **입력** | (선택) 앱 관리자 비밀번호 |
| **화면** | AdminPasswordModal |

## 5. 프로젝트

### FD-PROJ-00 승인된 회원의 프로젝트 보기
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-PROJ-00 |
| **기능명** | 승인된 회원의 프로젝트 목록 조회 |
| **설명** | 승인된 회원(profiles.approved = true)은 **프로젝트 보기가 가능**하다. 등록된 전체 프로젝트 목록을 조회할 수 있다. 프로젝트 내 작업(태스크) 내용은 해당 프로젝트의 멤버이거나 보기/편집 권한 요청이 승인된 경우에만 조회 가능하다. |
| **조건** | profiles.approved = true |
| **결과** | 프로젝트 목록 SELECT 권한 부여 |

### FD-PROJ-01 생명주기
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-PROJ-01 |
| **기능명** | 프로젝트 생성·수정·삭제·복사 |
| **설명** | 프로젝트를 생성하고, 이름·설명·기간 등을 수정·삭제할 수 있다. 프로젝트를 복사하면 소속 작업이 포함된 새 프로젝트가 생기며, 복사본은 나의 소유로 둔다. |
| **입력** | 이름, 설명, 시작일·종료일, (선택) 투입·주간보고 메타 등 |
| **결과** | 프로젝트 CRUD·복사본 생성(owner_id = 현재 사용자) |
| **화면** | ProjectModal, ProjectsPage |

### FD-PROJ-02 기간 규칙
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-PROJ-02 |
| **기능명** | 프로젝트 기간 내 작업 일정 제한 |
| **설명** | 프로젝트에 시작·종료 기간을 두면, 그 범위를 벗어나는 작업 일정은 허용하지 않는다. |
| **조건** | 프로젝트 start_date·end_date 설정 시 |
| **결과** | 작업 start_date·end_date가 프로젝트 기간 밖이면 검증 오류 또는 자동 보정 |

### FD-PROJ-03 투입·보고 메타
| 항목 | 내용 |
|------|------|
| **기능 ID** | FD-PROJ-03 |
| **기능명** | 투입 인원·비율·주간보고 필드 |
| **설명** | 프로젝트 단위로 투입 인원·투입 비율(%), 월별 투입을 둘 수 있다. 최소 작업 공수(일) 기준을 둘 수 있다. 주간보고용 필드(분류, 주관기관, 예산, 기간 표기, 과제명 약어/전체 등)를 둘 수 있다. |
| **데이터** | assignments(jsonb), minWorkEffortDays, reportCategory, reportAgency, reportBudgetThisYear, reportTotalPeriod, reportNameShort, reportNameFull |
| **화면** | ProjectModal, AllocationOverviewPage, WeeklyReportModal |
