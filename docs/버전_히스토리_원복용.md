# 버전 히스토리 (원복용)

원하는 버전으로 되돌리려면 터미널에서:
```powershell
cd d:\src\WBS_MG
git reset --hard <커밋해시>
```
개발 서버가 켜져 있으면 재시작하세요: `npm run dev`
