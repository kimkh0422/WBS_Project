## 0. 그룹 개요

### 0.1 범위

Excel·JSON 임포트와 익스포트, JSON 백업·복원, AI 분석·보정, 주간 보고 모달, 보고서 출력(PDF/이미지), 데이터 전체 초기화, 변경 이력 내보내기.

### 0.2 비-목표

- 임포트 결과 작업의 후속 편집 (→ FD-TM)
- 자동 일정 보정 (→ FD-SCH)
- AI 모델 자체의 성능·비용 — 외부 서비스 책임

### 0.3 주요 용어

| 용어 | 정의 |
|------|------|
| **임포트** | 외부 파일 → 앱 내 데이터로 적재 |
| **익스포트** | 앱 내 데이터 → 외부 파일 |
| **백업** | 앱 내 모든 데이터를 단일 JSON으로 저장 |
| **복원** | 백업 JSON으로 앱 내 데이터 일괄 교체 |
| **AI 분석** | LLM 기반 작업 추출·일정 추천·진척도 보정 등 |

## 1. 상세 기능 정의

### FD-IO-001 — Excel 임포트

| 메타 | 값 |
|------|----|
| 우선순위 | P1 |

#### 1. 목적

다른 도구(MS Project·MS Excel·Smartsheet)에서 만든 작업 표를 가져와 빠르게 시작한다.

#### 4. 처리 규칙

##### 4.1 진입

- 헤더 ⋮ → [Excel 가져오기] (관리자 또는 프로젝트 소유자).

##### 4.2 매핑 단계

- 1단계: 파일 업로드 (.xlsx).
- 2단계: 컬럼 매핑 미리보기 — 사용자가 Excel 컬럼 ↔ 작업 필드 매핑.
- 3단계: 행별 검증 표시 (오류·경고·정상). 오류 행은 임포트 제외.
- 4단계: [임포트] 클릭 → 모두 단일 트랜잭션으로 추가.

##### 4.3 매핑 가능 필드

- 작업명·시작일·종료일·공수·담당자·상태·가중치·메모·사용자 정의 컬럼.

##### 4.4 트리 구조 추론

- "WBS" 컬럼 또는 들여쓰기 레벨로 부모-자식 추론.
- 추론 실패 시 모두 루트로 적재.

##### 4.5 일정 클램프

- 임포트된 일정이 프로젝트 범위 밖이면 클램프 + 경고.

##### 4.6 권한

- 관리자 또는 대상 프로젝트의 소유자.

#### 11. 수용 기준

```
AC-FD-IO-001-1
  Given Excel 파일 100행, WBS 컬럼 = "1, 1.1, 1.2, ..."
  When 임포트 미리보기
  Then 트리 구조 자동 추론 (1.1, 1.2는 1의 자식)
       오류 행은 빨간 표시, 정상은 녹색

AC-FD-IO-001-2
  Given 행 5개 오류 (날짜 형식 불일치)
  When [임포트] 클릭
  Then 정상 95행만 적재, 오류 5행은 제외
       토스트 "95건 임포트 / 5건 오류"

AC-FD-IO-001-3
  Given 임포트된 일정이 프로젝트 범위 밖
  When 적재
  Then 프로젝트 범위로 클램프됨 + 토스트 안내
```

### FD-IO-002 — Excel 내보내기

| 메타 | 값 |
|------|----|
| 우선순위 | P1 |

#### 4. 처리 규칙

##### 4.1 진입

- 헤더 ⋮ → [내보내기] → Excel 옵션.

##### 4.2 옵션

- 대상: 현재 프로젝트 / 다중 선택 / 전체.
- 컬럼: 사용자가 표시할 컬럼 선택.
- 트리 구조: WBS 번호 컬럼 포함 / 들여쓰기 표시 / 평면 (flat).
- 시트 분리: 프로젝트별 시트 / 단일 시트.

##### 4.3 출력 형식

- `.xlsx` 다운로드.
- 헤더 행 굵게 + 색상.
- 마일스톤·이슈 표시 아이콘 → 텍스트로.
- 의존성: 콤마로 구분된 WBS 번호.

##### 4.4 마지막 사용 옵션 기억

- 다음 내보내기 시 직전 옵션 기본 표시.

#### 11. 수용 기준

```
AC-FD-IO-002-1
  Given 프로젝트 P (작업 200건)
  When [내보내기] → 옵션 [WBS 번호 + 들여쓰기] → [다운로드]
  Then P_2026-05-07.xlsx 다운로드
       시트에 200행, WBS 번호 + 들여쓰기 표시

AC-FD-IO-002-2
  Given 다중 프로젝트 [P1, P2] 선택
  When [내보내기] → 시트 분리 옵션
  Then 한 파일에 시트 2개 (P1, P2 각각)
```

### FD-IO-003 — JSON 백업

| 메타 | 값 |
|------|----|
| 우선순위 | P0 |

#### 4. 처리 규칙

##### 4.1 진입

- 헤더 ⋮ → [백업·복원] → [JSON 백업].

##### 4.2 출력

- 단일 JSON 파일. 모든 프로젝트·작업·환경설정·조직도·감사 로그 포함.
- 사용자별 즐겨찾기·관리자 정보는 제외 (보안).
- 파일명: `wbs-backup-{YYYY-MM-DD-HHmm}.json`.

##### 4.3 형식 버전

- JSON 최상위에 `schema_version` 명시 (마이그레이션 호환성).

##### 4.4 권한

- 관리자만.

##### 4.5 자동 백업 옵션

- 환경설정으로 주기적 자동 백업 (P3).

#### 11. 수용 기준

```
AC-FD-IO-003-1
  Given 관리자
  When [JSON 백업] 클릭
  Then 모든 프로젝트·작업·설정 포함된 JSON 다운로드
       파일에 schema_version 포함
```

### FD-IO-004 — JSON 복원

| 메타 | 값 |
|------|----|
| 우선순위 | P0 |

#### 4. 처리 규칙

##### 4.1 진입

- [백업·복원] → [JSON 복원] → 파일 선택.

##### 4.2 모드

- **전체 교체**: 현재 데이터를 모두 삭제 후 백업으로 교체 (확인 다이얼로그 + 이름 일치).
- **병합**: 백업 데이터를 현재 데이터에 병합 (ID 충돌 시 새 UUID 발급).

##### 4.3 사전 백업

- 복원 전 자동으로 현재 상태를 별도 백업 (롤백용).

##### 4.4 트랜잭션

- 모두 단일 트랜잭션 — 도중 실패 시 롤백.

##### 4.5 권한

- 관리자만.

#### 11. 수용 기준

```
AC-FD-IO-004-1
  Given JSON 백업 파일
  When [전체 교체] 모드 → 다이얼로그 "현재 데이터가 모두 삭제됩니다 — 'CONFIRM' 입력"
  Then 사용자가 'CONFIRM' 입력 후 [확인]
       기존 데이터 삭제 → 백업 데이터 적재
       현재 상태는 별도 자동 백업으로 보존

AC-FD-IO-004-2
  Given 복원 도중 데이터 일부 INSERT 실패
  When 트랜잭션 롤백
  Then 모든 변경 무효
       사용자에게 자동 백업 위치 안내 (수동 복원 가능)
```

### FD-IO-005 — AI 분석 (작업 추출·보정)

| 메타 | 값 |
|------|----|
| 우선순위 | P2 |

#### 1. 목적

자연어 메모·기획서·계약서 등을 입력하면 LLM이 작업 트리 후보를 제안하여 빠른 초안을 만든다. 또는 기존 작업의 일정·진척도·의존성을 분석하여 보정 제안.

#### 4. 처리 규칙

##### 4.1 진입

- 헤더 ⋮ → [AI 분석] (관리자만 / 또는 환경설정으로 일반 회원도 허용).

##### 4.2 모드

| 모드 | 입력 | 출력 |
|------|------|------|
| **작업 추출** | 자유 텍스트 (기획서·메모) | 작업 트리 제안 |
| **일정 추천** | 현재 작업 트리 + 우선순위 힌트 | 일정·의존성 제안 |
| **진척도 보정** | 작업의 메모·체크리스트 | progress 추정 |
| **WBS 정정** | 현재 트리 | 누락·중복·일관성 검토 |

##### 4.3 결과 미리보기

- 제안된 변경을 표 형태로 미리보기. 사용자가 항목별 [수락]/[거절].
- 잠금 필드는 AI 제안에서 자동 제외(보호).

##### 4.4 외부 API

- LLM 키는 환경변수(`VITE_AI_API_KEY`) 또는 사용자 환경설정에 저장.
- 키 없으면 AI 메뉴 비활성.

##### 4.5 비용 안내

- 분석 시작 전 예상 토큰 수·비용 표시.

##### 4.6 권한

- `effectiveIsAdmin` (현재 코드 기본).

#### 11. 수용 기준

```
AC-FD-IO-005-1
  Given AI 키 설정됨, 관리자
  When [AI 분석] → 작업 추출 모드 → 메모 붙여넣기 → [분석]
  Then 토큰 수·예상 비용 표시
       사용자 확인 후 LLM 호출
       결과 = 작업 트리 후보, 표 미리보기

AC-FD-IO-005-2
  Given 미리보기, 작업 T (잠금 필드 progress 포함)
  When AI 결과 적용
  Then T.progress 미변경 (잠금 보호)
       다른 필드는 사용자 [수락] 항목만 적용
```

### FD-IO-006 — 주간 보고 모달

| 메타 | 값 |
|------|----|
| 우선순위 | P2 |

#### 1. 목적

주 단위로 본인 진행 작업·이슈·다음 주 계획을 입력하고 PDF/이미지로 출력한다.

#### 4. 처리 규칙

##### 4.1 진입

- 헤더 ⋮ → [주간 보고].

##### 4.2 자동 채움

- 이번 주 시작/종료 작업 자동 나열 (필터: 본인 담당 + 주간 범위).
- 이슈 마킹된 작업.
- 진척도 변화.

##### 4.3 사용자 입력

- 자유 텍스트 ("주요 성과", "이슈 및 대응", "다음 주 계획").

##### 4.4 출력

- 미리보기 → [PDF 다운로드] / [이미지 저장] / [클립보드 복사 (HTML)].

##### 4.5 작업 추가

- 주간 보고 안에서 [+ 작업 추가] (FD-TM-001 진입점 — 보고 컨텍스트의 프로젝트로 추가).

#### 11. 수용 기준

```
AC-FD-IO-006-1
  Given 사용자 X, 이번 주 본인 담당 작업 5건
  When [주간 보고] 진입
  Then 작업 5건 자동 나열, 이슈 작업은 빨간 마킹

AC-FD-IO-006-2
  Given 보고 작성 후
  When [PDF 다운로드]
  Then 주간보고서.pdf 다운로드, 회사 로고·기간·주요 성과·이슈·계획 포함
```

### FD-IO-007 — 보고서 출력 (PDF/이미지)

| 메타 | 값 |
|------|----|

  When [PDF 출력] → 가로 A4 → [다운로드]

### FD-IO-008 — 데이터 전체 초기화

| 메타 | 값 |
|------|----|
| 우선순위 | P1 |

#### 1. 목적

신규 환경 셋업·테스트 후 모든 데이터 정리.

#### 4. 처리 규칙

##### 4.1 진입

- 헤더 ⋮ → [데이터 초기화] (관리자 전용).

##### 4.2 옵션

- 모든 프로젝트·작업·감사 로그 삭제.
- 환경설정·조직도·회원: 유지 / 삭제 옵션.

##### 4.3 안전 장치

- 다이얼로그에서 "INITIALIZE"라는 텍스트 정확히 입력해야 진행.
- 자동으로 사전 백업 다운로드 강제 (백업 안 하면 진행 차단).

##### 4.4 영향

- 클라우드 모드: DB까지 삭제. 다른 사용자에게 동기화 시 반영.
- 로컬 모드: 로컬만.

#### 11. 수용 기준

```
AC-FD-IO-008-1
  Given 관리자, [데이터 초기화]
  When 다이얼로그 "사전 백업 필요" → [백업 다운로드]
  Then 자동 백업 다운로드
       이후 "INITIALIZE" 입력 → [확인]
       모든 프로젝트·작업·감사 로그 삭제

AC-FD-IO-008-2
  Given 백업 다운로드 안 함
  When [확인] 클릭
  Then 차단 + "백업 후 다시 시도" 안내
```
